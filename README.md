# Vault для Android

Официальные сборки VPN-клиента **Vault** для Android-телефонов и планшетов.

**[⬇ Скачать последнюю версию](https://github.com/vault-apps/android/releases/latest)**

## Установка

1. Откройте [страницу последнего релиза](https://github.com/vault-apps/android/releases/latest) и скачайте файл `vault-<версия>.apk`.
2. Откройте скачанный файл. Если Android попросит, разрешите установку приложений из этого источника (браузера или файлового менеджера).
3. Запустите Vault и войдите по ссылке доступа. Её можно получить в [личном кабинете](https://lk.vault-app.ru) или в Telegram-боте [@vault_vpnbot](https://t.me/vault_vpnbot).

**Требования:** Android 7.0 или новее. Поддерживаются телефоны и планшеты.

## Обновления

Vault обновляется сам: при запуске приложение проверяет новые релизы в этом репозитории и предлагает скачать и установить обновление. Проверить вручную можно в **Настройки → О приложении → Проверить обновления**.

> **Если у вас установлена версия 1.0.4 или старее:** перед установкой 1.0.5 удалите прежнюю версию Vault. Начиная с 1.0.5 приложение подписано новым ключом, поэтому поверх старых версий оно не встанет. После переустановки войдите заново. Следующие обновления будут ставиться поверх, без удаления.

## Подлинность

Скачивайте Vault только со [страницы релизов](https://github.com/vault-apps/android/releases) этого репозитория. Все сборки подписаны одним ключом, отпечаток сертификата SHA-256:

```
FA:3A:02:08:15:A2:23:1A:07:FB:F9:E8:AD:0B:AD:39:96:E4:72:4F:D7:3D:27:CB:6E:26:30:5E:32:DD:E2:12
```

Проверить подпись скачанного файла можно утилитой `apksigner` из Android SDK:

```
apksigner verify --print-certs vault-<версия>.apk
```

Обновление, подписанное другим ключом, Android не установит поверх уже установленного Vault.
